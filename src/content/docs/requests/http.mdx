An HTTP request is the everyday request: one call to a REST API with a method and a URL. Follow the two examples below to send one yourself in a few minutes. You do not need an account or a contract.

<video controls muted playsinline preload="metadata" poster="/media/en/request-from-curl.webp" src="/media/en/request-from-curl.mp4"></video>

## Example 1: read a post with GET

[JSONPlaceholder](https://jsonplaceholder.typicode.com) is a free practice API. This request reads post number 1.

<Steps>

1. In the sidebar, open your collection and click **New request**. The **New request** dialog opens.
2. Choose **HTTP**. A request named **New request** opens in its own tab, with the method **GET**.
3. Click the URL field and write `https://jsonplaceholder.typicode.com/posts/1`.
4. Press **Send** (⌘/Ctrl + Enter). The response opens below the request.

</Steps>

![A single request with its method, URL, tabs and the response below](/media/en/request.webp)

The status bar says `200 OK`, followed by the time and the size. The **Body** tab holds the answer:

```json
{
  "userId": 1,
  "id": 1,
  "title": "sunt aut facere repellat provident occaecati excepturi optio reprehenderit",
  "body": "quia et suscipit\nsuscipit recusandae consequuntur expedita et cum\nreprehenderit molestiae ut ut quas totam\nnostrum rerum est autem sunt rem eveniet architecto"
}
```

The same call in a terminal, to compare:

```bash
curl https://jsonplaceholder.typicode.com/posts/1
```

## Example 2: create a post with POST

A POST sends data to the API. This one creates a post.

<Steps>

1. Click **New request** and choose **HTTP**, as before.
2. Open the method menu (it says **GET**) and choose **POST**.
3. Write the URL `https://jsonplaceholder.typicode.com/posts`.
4. Open the **Body** tab and choose **JSON** in the menu at the top.
5. Write the body in the editor:

   ```json
   {
     "title": "Hello Luvin",
     "body": "My first post",
     "userId": 1
   }
   ```

6. Press **Send** (⌘/Ctrl + Enter).

</Steps>

The status is `201 Created`, and the body echoes your post with an `id` that the API gave it:

```json
{
  "title": "Hello Luvin",
  "body": "My first post",
  "userId": 1,
  "id": 101
}
```

Luvin added the header `Content-Type: application/json` for you, because the body type is **JSON**. Open **Sent request** in the response to see every header that went out.

<Aside type="note">
JSONPlaceholder only pretends to save: the `id` is always `101` and the post is not stored. A real API would keep it.
</Aside>

## The methods

The method tells the API what you want to do. Choose it in the menu at the left of the URL.

| Method | Typical use |
|---|---|
| **GET** | Read data. No body is sent. |
| **POST** | Create something, or send data to process. |
| **PUT** | Replace something that exists. |
| **PATCH** | Change part of something that exists. |
| **DELETE** | Remove something. |
| **HEAD** | Like GET, but the API answers with the headers only. No body is sent. |
| **OPTIONS** | Ask what the API allows. |

Each method has its own color, in the menu and in the sidebar.

To use another method, such as `QUERY` or `PURGE`, type it in **Type another method** at the bottom of the menu and press Enter. Luvin saves it in capitals and sends it as it is. It takes letters, digits and `- _ . ~`, without spaces. Its badge is gray.

![The method menu: each method with its color, and Type another method at the bottom](/media/en/request-methods.webp)

:::caution
A body is not sent with GET or HEAD. See [Params, headers and body](/requests/params-headers-body/).
:::

## The URL bar

| You write | What Luvin does |
|---|---|
| `{{baseUrl}}/posts/1` | Replaces `{{baseUrl}}` with the value of the active environment when you send. Switch environment and the same request goes to another server. |
| `https://api.example.com/posts?userId=1` | Moves what follows `?` to the **Params** tab, and keeps both in sync. |
| `api.example.com/posts` | Adds `http://` in front when you leave out the scheme. |
| `https://api.example.com//posts` | Collapses repeated slashes in the path to one. |
| A pasted cURL command | Fills the whole request. See [cURL](/requests/curl/). |

Type `{{` in the field to pick a variable. See [Variables and secrets](/environments/variables-and-secrets/).

**Send** stays disabled while the URL is empty. While a request is on its way the button becomes **Cancel**.

## Send from the keyboard

| Keys | Where | What it does |
|---|---|---|
| **Enter** | In the URL field | Sends the request. If the list of `{{variables}}` is open, Enter picks the variable instead. **Shift + Enter** does not send. |
| **⌘ + Enter** (**Ctrl + Enter**) | Anywhere in the request: the URL, the tabs, the body editor | Sends the request. |

Both work in HTTP, GraphQL and gRPC requests. They do not send a WebSocket message. With a dialog open, ⌘/Ctrl + Enter belongs to the dialog.

## Read the answer

- **Status.** `2xx` means success, `4xx` means the request has a problem, `5xx` means the server failed. Luvin colors each family.
- **Body.** The answer. **Pretty** formats it, **Raw** shows it as it came.
- **Headers** and **Cookies.** What the API sent besides the body.
- **Sent request.** What Luvin really sent, to check your own side.

Every part of the response is explained in [Read a response in detail](/requests/response-details/).
