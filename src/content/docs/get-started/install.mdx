Luvin is a desktop app for macOS and Windows. Everything runs on your computer: there is no backend and no account.

```bash title="From the Luvin project folder"
npm install          # once
npm run desktop:dev  # opens the app
```

<Aside>
There is no public download yet. You run Luvin from its project folder or build the installer yourself.
</Aside>

## Requirements

- **Node.js 20.19 or later, or 22.12 or later.** Check with `node --version`.
- **npm**, which comes with Node.js.
- The Luvin project folder on your computer.

## Start Luvin

<Steps>

1. Open a terminal in the Luvin project folder.
2. Install the dependencies (once):

   ```bash
   npm install
   ```

3. Start the app:

   ```bash
   npm run desktop:dev
   ```

</Steps>

A Luvin window opens with the welcome screen.

## Build the installers

<Steps>

1. In the project folder, run:

   ```bash
   npm run desktop:build
   ```

2. Open the `release/` folder. The installer is there.

</Steps>

| System | What is built |
|---|---|
| macOS | A `.dmg` for Apple Silicon and one for Intel |
| Windows | An installer (NSIS) |

### Open an unsigned installer

The installers are not signed yet, so your system warns you the first time.

<Tabs>
<TabItem label="macOS">

1. Drag Luvin to **Applications** and open it. macOS says it cannot verify the app. Click **Done**.
2. Open **System Settings → Privacy & Security** and scroll down to **Security**.
3. Next to the message about Luvin, click **Open Anyway** and confirm with your password.

You only do this the first time. Since macOS Sequoia (15), right-clicking the app and choosing **Open** no longer skips the warning.

</TabItem>
<TabItem label="Windows">

1. Run the installer.
2. In the warning, click **More info**.
3. Click **Run anyway**.

</TabItem>
</Tabs>
